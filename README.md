# IDS ChildShield Climate AI – Frontend Platform

IDS ChildShield Climate AI is an open-source climate-health platform designed to protect children in climate-vulnerable communities.

This frontend platform provides:

- Climate-health dashboards
- Campaign creation and communication management
- Risk visualization and analytics
- NGO and clinic operational interfaces
- User communication workflows

## Technology Stack

- Angular
- TypeScript
- Tailwind CSS
